## Function `extract_`

Get a <code>Balance&lt;T&gt;</code> from a <code>Bag</code>.
Aborts if the balance is zero or if there is no balance for the type <code>T</code>.


<pre>
<code>
<b>fun</b> <Link to="../stardust/utilities#stardust_utilities_extract_">extract_</Link>&lt;T&gt;(bag: &<b>mut</b> <Link to="../iota/bag#iota_bag_Bag">iota::bag::Bag</Link>): <Link to="../iota/balance#iota_balance_Balance">iota::balance::Balance</Link>&lt;T&gt;
</code>
</pre>



<details>
<summary>Implementation</summary>


<pre>
<code>
<b>fun</b> <Link to="../stardust/utilities#stardust_utilities_extract_">extract_</Link>&lt;T&gt;(bag: &<b>mut</b> Bag): Balance&lt;T&gt; \{
    <b>let</b> key = type_name::get&lt;T&gt;().into_string();
    // This call aborts <b>if</b> the key doesn't exist.
    <b>let</b> balance: Balance&lt;T&gt; = bag.remove(key);
    <b>assert</b>!(balance.value() != 0, <Link to="../stardust/utilities#stardust_utilities_EZeroNativeTokenBalance">EZeroNativeTokenBalance</Link>);
    balance
}
</code>
</pre>



</details>
