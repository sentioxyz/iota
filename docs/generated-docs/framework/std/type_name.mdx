<details>
<summary>Fields</summary>


<dl>
<dt>
<code>name: <Link to="../std/ascii#std_ascii_String">std::ascii::String</Link></code>
</dt>
<dd>
 String representation of the type. All types are represented
 using their source syntax:
 "u8", "u64", "bool", "address", "vector", and so on for primitive types.
 Struct types are represented as fully qualified type names; e.g.
 <code>00000000000000000000000000000001::string::String</code> or
 <code>0000000000000000000000000000000a::module_name1::type_name1&lt;0000000000000000000000000000000a::module_name2::type_name2&lt;<Link to="../std/u64#std_u64">u64</Link>&gt;&gt;</code>
 Addresses are hex-encoded lowercase values of length ADDRESS_LENGTH (16, 20, or 32 depending on the Move platform)
</dd>
</dl>

    // Base16 (<Link to="../std/string#std_string">string</Link>) representation of an <b>address</b> <b>has</b> 2 symbols per byte.

        i = i + 1;
    };

}
