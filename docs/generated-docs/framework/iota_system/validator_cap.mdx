## Struct `UnverifiedValidatorOperationCap`

The capability object is created when creating a new <code>Validator</code> or when the
validator explicitly creates a new capability object for rotation/revocation.
The holder address of this object can perform some validator operations on behalf of
the authorizer validator. Thus, if a validator wants to separate the keys for operation
(such as reference gas price setting or tallying rule reporting) from fund/staking, it
could transfer this capability object to another address.
To facilitate rotating/revocation, <code>Validator</code> stores the ID of currently valid
<code><Link to="../iota_system/validator_cap#iota_system_validator_cap_UnverifiedValidatorOperationCap">UnverifiedValidatorOperationCap</Link></code>. Thus, before converting <code><Link to="../iota_system/validator_cap#iota_system_validator_cap_UnverifiedValidatorOperationCap">UnverifiedValidatorOperationCap</Link></code>
to <code><Link to="../iota_system/validator_cap#iota_system_validator_cap_ValidatorOperationCap">ValidatorOperationCap</Link></code>, verification needs to be done to make sure
the cap object is still valid.

<code>
<b>public</b>(package) <b>fun</b> <Link to="../iota_system/validator_cap#iota_system_validator_cap_new_unverified_validator_operation_cap_and_transfer">new_unverified_validator_operation_cap_and_transfer</Link>(
    validator_address: <b>address</b>,
    ctx: &<b>mut</b> TxContext,
): ID \{
    // This function needs to be called only by the <Link to="../iota_system/validator#iota_system_validator">validator</Link> itself, except
    // 1. in <Link to="../iota_system/genesis#iota_system_genesis">genesis</Link> where all validators are created by @0x0
    // 2. in tests where @0x0 could be used to simplify the setup
    <b>let</b> sender_address = ctx.sender();
    <b>assert</b>!(sender_address == @0x0 || sender_address == validator_address, 0);
    <b>let</b> operation_cap = <Link to="../iota_system/validator_cap#iota_system_validator_cap_UnverifiedValidatorOperationCap">UnverifiedValidatorOperationCap</Link> \{
        id: object::new(ctx),
        authorizer_validator_address: validator_address,
    };
    <b>let</b> operation_cap_id = object::id(&operation_cap);
    transfer::public_transfer(operation_cap, validator_address);
    operation_cap_id
}
