<Link id="iota_system_voting_power_TOTAL_VOTING_POWER"></Link>

Set total_voting_power as 10_000 by convention. Individual voting powers can be interpreted
as easily understandable basis points (e.g., voting_power: 100 = 1%, voting_power: 1 = 0.01%) rather than
opaque quantities whose meaning changes from epoch to epoch as the total amount staked shifts.
Fixing the total voting power allows clients to hardcode the quorum threshold and total_voting power rather
than recomputing these.

## Function `set_voting_power`

Set the voting power of committee validators.
Each committee validator's voting power is initialized using their stake. We then attempt to cap their voting power
at <code><Link to="../iota_system/voting_power#iota_system_voting_power_MAX_VOTING_POWER">MAX_VOTING_POWER</Link></code>. If <code><Link to="../iota_system/voting_power#iota_system_voting_power_MAX_VOTING_POWER">MAX_VOTING_POWER</Link></code> is not a feasible cap, we pick the lowest possible cap.

## Function `init_voting_power_info`

Create the initial voting power of each committee member, set using their stake, but capped using threshold.
We also perform insertion sort while creating the voting power list, by maintaining the list in
descending order using voting power.
Anything beyond the threshold is added to the remaining_power, which is also returned.

<pre>
<code>
<b>fun</b> <Link to="../iota_system/voting_power#iota_system_voting_power_adjust_voting_power">adjust_voting_power</Link>(
    info_list: &<b>mut</b> vector&lt;<Link to="../iota_system/voting_power#iota_system_voting_power_VotingPowerInfoV1">VotingPowerInfoV1</Link>&gt;,
    threshold: u64,
    <b>mut</b> remaining_power: u64,
) \{
    <b>let</b> <b>mut</b> i = 0;
    <b>let</b> len = info_list.length();
    <b>while</b> (i &lt; len && remaining_power &gt; 0) \{
        <b>let</b> v = &<b>mut</b> info_list[i];
        // planned is the amount of extra power we want to distribute to this <Link to="../iota_system/validator#iota_system_validator">validator</Link>.
        <b>let</b> planned = remaining_power.divide_and_round_up(len - i);
        // target is the targeting power this <Link to="../iota_system/validator#iota_system_validator">validator</Link> will reach, capped by threshold.
        <b>let</b> target = threshold.min(v.<Link to="../iota_system/voting_power#iota_system_voting_power">voting_power</Link> + planned);
        // actual is the actual amount of power we will be distributing to this <Link to="../iota_system/validator#iota_system_validator">validator</Link>.
        <b>let</b> actual = remaining_power.min(target - v.<Link to="../iota_system/voting_power#iota_system_voting_power">voting_power</Link>);
        v.<Link to="../iota_system/voting_power#iota_system_voting_power">voting_power</Link> = v.<Link to="../iota_system/voting_power#iota_system_voting_power">voting_power</Link> + actual;
        <b>assert</b>!(v.<Link to="../iota_system/voting_power#iota_system_voting_power">voting_power</Link> &lt;= threshold, <Link to="../iota_system/voting_power#iota_system_voting_power_EVotingPowerOverThreshold">EVotingPowerOverThreshold</Link>);
        remaining_power = remaining_power - actual;
        i = i + 1;
    };
    <b>assert</b>!(remaining_power == 0, <Link to="../iota_system/voting_power#iota_system_voting_power_ETotalPowerMismatch">ETotalPowerMismatch</Link>);
}

<code>
<b>fun</b> <Link to="../iota_system/voting_power#iota_system_voting_power_update_voting_power">update_voting_power</Link>(
    validators: &<b>mut</b> vector&lt;ValidatorV1&gt;,

    // First, set the voting power of all active validators to 0.
    <b>let</b> <b>mut</b> i = 0;

    <b>while</b> (info_list.length() != 0) \{
        <b>let</b> <Link to="../iota_system/voting_power#iota_system_voting_power_VotingPowerInfoV1">VotingPowerInfoV1</Link> \{

            stake: _,

        <b>let</b> v = &<b>mut</b> validators[validator_index];
        v.<Link to="../iota_system/voting_power#iota_system_voting_power_set_voting_power">set_voting_power</Link>(<Link to="../iota_system/voting_power#iota_system_voting_power">voting_power</Link>);
    };
    info_list.destroy_empty();
}

<pre>
<code>
<b>fun</b> <Link to="../iota_system/voting_power#iota_system_voting_power_check_invariants">check_invariants</Link>(committee_members: &vector&lt;u64&gt;, validators: &vector&lt;ValidatorV1&gt;) \{
    // First check that the total voting power must be <Link to="../iota_system/voting_power#iota_system_voting_power_TOTAL_VOTING_POWER">TOTAL_VOTING_POWER</Link>.
    <b>let</b> <Link to="../iota_system/voting_power#iota_system_voting_power_total_voting_power">total_voting_power</Link> = validators.take_fold_ref!(committee_members, 0, |total, v| \{
        <b>let</b> <Link to="../iota_system/voting_power#iota_system_voting_power">voting_power</Link> = v.<Link to="../iota_system/voting_power#iota_system_voting_power">voting_power</Link>();
        <b>assert</b>!(<Link to="../iota_system/voting_power#iota_system_voting_power">voting_power</Link> &gt; 0, <Link to="../iota_system/voting_power#iota_system_voting_power_EInvalidVotingPower">EInvalidVotingPower</Link>);
        total + <Link to="../iota_system/voting_power#iota_system_voting_power">voting_power</Link>
    });
    <b>assert</b>!(<Link to="../iota_system/voting_power#iota_system_voting_power_total_voting_power">total_voting_power</Link> == <Link to="../iota_system/voting_power#iota_system_voting_power_TOTAL_VOTING_POWER">TOTAL_VOTING_POWER</Link>, <Link to="../iota_system/voting_power#iota_system_voting_power_ETotalPowerMismatch">ETotalPowerMismatch</Link>);
    // Second check that <b>if</b> <Link to="../iota_system/validator#iota_system_validator">validator</Link> A's stake is larger than B's stake, A's voting power must be no less
    // than B's voting power; similarly, <b>if</b> A's stake is less than B's stake, A's voting power must be no larger
    // than B's voting power.
    <b>let</b> committee_length = committee_members.length();
    <b>let</b> <b>mut</b> a = 0;
    <b>while</b> (a &lt; committee_length) \{
        <b>let</b> <b>mut</b> b = a + 1;
        <b>while</b> (b &lt; committee_length) \{
            // No need to check <b>if</b> [a;b] &lt; validators_length because it was checked in the previous <b>loop</b> already.
            <b>let</b> validator_a = &validators[committee_members[a]];
            <b>let</b> validator_b = &validators[committee_members[b]];
            <b>let</b> stake_a = validator_a.total_stake();
            <b>let</b> stake_b = validator_b.total_stake();
            <b>let</b> power_a = validator_a.<Link to="../iota_system/voting_power#iota_system_voting_power">voting_power</Link>();
            <b>let</b> power_b = validator_b.<Link to="../iota_system/voting_power#iota_system_voting_power">voting_power</Link>();
            <b>if</b> (stake_a &gt; stake_b) \{
                <b>assert</b>!(power_a &gt;= power_b, <Link to="../iota_system/voting_power#iota_system_voting_power_ERelativePowerMismatch">ERelativePowerMismatch</Link>);
            };

                <b>assert</b>!(power_a &lt;= power_b, <Link to="../iota_system/voting_power#iota_system_voting_power_ERelativePowerMismatch">ERelativePowerMismatch</Link>);
            };
            b = b + 1;
        };
        a = a + 1;
    }
