## Struct `StorageFundV1`

Struct representing the storage fund, containing two <code>Balance</code>s:
- <code><Link to="../iota_system/storage_fund#iota_system_storage_fund_total_object_storage_rebates">total_object_storage_rebates</Link></code> has the invariant that it's the sum of <code>storage_rebate</code> of
all objects currently stored on-chain. To maintain this invariant, the only inflow of this
balance is storage charges collected from transactions, and the only outflow is storage rebates
of transactions, including both the portion refunded to the transaction senders as well as
the non-refundable portion taken out and put into <code>non_refundable_balance</code>.
- <code>non_refundable_balance</code> contains any remaining inflow of the storage fund that should not
be taken out of the fund.

<pre>
<code>
<b>public</b>(package) <b>fun</b> <Link to="../iota_system/storage_fund#iota_system_storage_fund_advance_epoch">advance_epoch</Link>(
    self: &<b>mut</b> <Link to="../iota_system/storage_fund#iota_system_storage_fund_StorageFundV1">StorageFundV1</Link>,
    storage_charges: Balance&lt;IOTA&gt;,
    storage_rebate_amount: u64,
    non_refundable_storage_fee_amount: u64,
): Balance&lt;IOTA&gt; \{
    // The storage charges <b>for</b> the epoch come from the storage rebate of the <Link to="../iota_system/storage_fund#iota_system_storage_fund_new">new</Link> objects created
    // and the <Link to="../iota_system/storage_fund#iota_system_storage_fund_new">new</Link> storage rebates of the objects modified during the epoch so we put the charges
    // into `<Link to="../iota_system/storage_fund#iota_system_storage_fund_total_object_storage_rebates">total_object_storage_rebates</Link>`.
    self.<Link to="../iota_system/storage_fund#iota_system_storage_fund_total_object_storage_rebates">total_object_storage_rebates</Link>.join(storage_charges);
    // Split out the non-refundable portion of the storage rebate and put it into the non-refundable balance.
    <b>let</b> non_refundable_storage_fee = self
        .<Link to="../iota_system/storage_fund#iota_system_storage_fund_total_object_storage_rebates">total_object_storage_rebates</Link>
        .split(non_refundable_storage_fee_amount);
    self.non_refundable_balance.join(non_refundable_storage_fee);
    // `storage_rebates` include the already refunded rebates of deleted objects and old rebates of modified objects and
    // should be taken out of the `<Link to="../iota_system/storage_fund#iota_system_storage_fund_total_object_storage_rebates">total_object_storage_rebates</Link>`.
    <b>let</b> storage_rebate = self.<Link to="../iota_system/storage_fund#iota_system_storage_fund_total_object_storage_rebates">total_object_storage_rebates</Link>.split(storage_rebate_amount);
    // The storage rebate <b>has</b> already been returned to individual transaction senders' gas coins
    // so we <b>return</b> the balance to be burnt at the very end of epoch change.
    storage_rebate
}
</code>
