<Link id="iota_dynamic_object_field"/>
Similar to <code><Link to="../iota/dynamic_field#iota_dynamic_field">iota::dynamic_field</Link></code>, this module allows for the access of dynamic fields. But
unlike, <code><Link to="../iota/dynamic_field#iota_dynamic_field">iota::dynamic_field</Link></code> the values bound to these dynamic fields _must_ be objects
themselves. This allows for the objects to still exist within in storage, which may be important
for external tools. The difference is otherwise not observable from within Move.
