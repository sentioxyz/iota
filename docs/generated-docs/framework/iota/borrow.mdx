<Link id="iota_borrow"/>
A simple library that enables hot-potato-locked borrow mechanics.

With Programmable transactions, it is possible to borrow a value within
a transaction, use it and put back in the end. Hot-potato <code><Link to="../iota/borrow#iota_borrow_Borrow">Borrow</Link></code> makes
sure the object is returned and was not swapped for another one.
