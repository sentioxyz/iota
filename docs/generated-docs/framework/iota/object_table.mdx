<Link id="iota_object_table"/>
Similar to <code><Link to="../iota/table#iota_table">iota::table</Link></code>, an <code><Link to="../iota/object_table#iota_object_table_ObjectTable">ObjectTable</Link>&lt;K, V&gt;</code> is a map-like collection. But unlike
<code><Link to="../iota/table#iota_table">iota::table</Link></code>, the values bound to these dynamic fields _must_ be objects themselves. This allows
for the objects to still exist within in storage, which may be important for external tools.
The difference is otherwise not observable from within Move.
