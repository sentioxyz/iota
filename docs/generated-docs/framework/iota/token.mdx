<Link id="iota_token"/>
The Token module which implements a Closed Loop Token with a configurable
policy. The policy is defined by a set of rules that must be satisfied for
an action to be performed on the token.

The module is designed to be used with a <code>TreasuryCap</code> to allow for minting
and burning of the <code><Link to="../iota/token#iota_token_Token">Token</Link></code>s. And can act as a replacement / extension or a
companion to existing open-loop (<code>Coin</code>) systems.

```
Module:      iota::balance       iota::coin             iota::token
Main type:   `Balance<T>`         `Coin<T>`               `Token<T>`
Capability:  `Supply<T>`  <---->  `TreasuryCap<T>` <----> `TreasuryCap<T>`
Abilities:   store              key + store           key
```

The Token system allows for fine-grained control over the actions performed
on the token. And hence it is highly suitable for applications that require
control over the currency which a simple open-loop system can't provide.

## Struct `TokenPolicy`

<code><Link to="../iota/token#iota_token_TokenPolicy">TokenPolicy</Link></code> represents a set of rules that define what actions can be
performed on a <code><Link to="../iota/token#iota_token_Token">Token</Link></code> and which <code>Rules</code> must be satisfied for the
action to succeed.

- For the sake of availability, <code><Link to="../iota/token#iota_token_TokenPolicy">TokenPolicy</Link></code> is a <code><Link to="../iota/token#iota_token_key">key</Link></code>-only object.
- Each <code><Link to="../iota/token#iota_token_TokenPolicy">TokenPolicy</Link></code> is managed by a matching <code><Link to="../iota/token#iota_token_TokenPolicyCap">TokenPolicyCap</Link></code>.
- For an action to become available, there needs to be a record in the
<code><Link to="../iota/token#iota_token_rules">rules</Link></code> VecMap. To allow an action to be performed freely, there's an
<code><Link to="../iota/token#iota_token_allow">allow</Link></code> function that can be called by the <code><Link to="../iota/token#iota_token_TokenPolicyCap">TokenPolicyCap</Link></code> owner.


<pre>
<code>
<b>public</b> <b>struct</b> <Link to="../iota/token#iota_token_TokenPolicy">TokenPolicy</Link>&lt;<b>phantom</b> T&gt; <b>has</b> <Link to="../iota/token#iota_token_key">key</Link>
</code>
</pre>

<summary>Fields</summary>


<dl>
<dt>
<code>id: <Link to="../iota/object#iota_object_UID">iota::object::UID</Link></code>
</dt>
<dd>
</dd>

<code><Link to="../iota/token#iota_token_spent_balance">spent_balance</Link>: <Link to="../iota/balance#iota_balance_Balance">iota::balance::Balance</Link>&lt;T&gt;</code>

 The balance that is effectively spent by the user on the "spend"

<dt>

 The set of rules that define what actions can be performed on the

 satisfied for the <code><Link to="../iota/token#iota_token_ActionRequest">ActionRequest</Link></code> to be confirmed.
</dd>
